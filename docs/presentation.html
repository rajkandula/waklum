AI-native project management: an AI project manager inside the app, and a connector so Claude or ChatGPT can work on your board from a conversation.

Open source, MIT Next.js 16 MongoDB MCP + OAuth (PKCE S256)

The problem

Keeping a project board current is manual work.

1

Every task is a form

Title, priority, due date, assignee, column: planning a week means dozens of them.

2

Assistants can't reach the board

You plan with Claude or ChatGPT, then copy the result into the tracker by hand.

3

Context resets every chat

Preferences and past decisions are gone, so you explain them again.

The solution

A tracker that AI can read and change.

The workspace

Boards, docs, files

  • Workspaces with owner, admin, manager, member, guest
  • Kanban, list, timeline and summary views
  • Docs, files, comments, notifications
In the app

AI project manager

  • Gemini with 13 tools: create, assign, move, write docs
  • Proposes a full plan, acts on your yes
  • Remembers facts per user and workspace
From any assistant

MCP connector

  • 11 tools for workspaces, projects, tasks, docs
  • Connect with OAuth or an API key
  • Metered per workspace per month

How it works

One Next.js server and one MongoDB.

How it works: the connector

Any MCP client connects itself.

1

Discover

Reads /.well-known metadata: endpoints, code flow, S256 only.

2

Register

Sends its redirect URIs and gets its own client id.

3

Approve

You sign in and approve on a consent page that cannot be framed.

4

Exchange

Code plus verifier (PKCE S256), single use, becomes an API key.

5

Call tools

Bearer key on /api/mcp; each call checks the workspace and its monthly quota.

Nothing hard-coded, nothing in memory: clients register themselves, and each MCP request builds its own server and transport.
